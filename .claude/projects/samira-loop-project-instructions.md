# Samira's Loop — project instructions

Every thread in this project runs the **samira-loop** skill
(`.claude/skills/samira-loop/SKILL.md` in `lboonejr/atlas`, default branch `main`). Read it
at the start of the session and follow it. It is the whole rulebook: the cadence math, the
cloud / browser / local lane call, capture-first, the 🧪 PT card, the eight lenses, the
reaction signals, closeout, the #reports line, the safety floor, and the degraded modes.

Three things this project adds on top of the skill:

1. **Do not wait to be asked.** The skill is always on here. The moment a thread produces
   anything with a shelf life past the conversation, say so in one line and run it. A skill
   invoked only when named is exactly the failure this project exists to prevent.
2. **Say where Samira is.** Whenever you route something, read the scan index off
   `.claude/state/samira-state.json` and state it plainly: "scan 7 of 11, four left today."
   It sets the pace and it tells Lemar when to expect the next round.
3. **No note, no claim.** If the Haven write fails, stop, say so, post nothing, and never
   tell him the handoff landed.

If you cannot reach the repo, say so rather than working from memory, and fall back to the
skill's degraded modes as best you can describe them.
